# CrucibleEngine roadmap

Status: **done** (implemented and tested), **partial**, **planned**. Sound features relative to Serum 2 are tracked
in `synth/ROADMAP.md`.

## Architecture

| item | status |
| --- | --- |
| Standalone library, no JUCE, C++ facade | done |
| Module registry; parameter model and FX chain built from it; product layouts | done |

| Generic modulation targets, assignable routes, modulated-value read-back | done |
| EngineConfig: voice pool 1-64, block size, quality policy, seed | done |

| C API (`crucible.h`), tested from C | done |
| `crucible-render` CLI (patch + MIDI / score to WAV, module and parameter listings) | done |
| Golden renders, parity, determinism, fuzzing, sanitizer CI script, per-module bench | done |
| Master metering: peak / clip, loudness, true peak, correlation, scope, spectrum | done |
| SIMD wrapper (NEON / SSE / AVX2 gathers / scalar), `CRUCIBLE_FORCE_SCALAR` fallback, x86_64 CI under Rosetta | done: convolver, warp kernels, half-band decimators |
| Voice graph: oscillator / filter slots, configurable counts, serial / parallel / split routing | done (filters are models of one filter unit, not modules) |
